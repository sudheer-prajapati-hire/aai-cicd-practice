# AAI DevOps CI/CD Practice Project

This repository is used for practicing automated CI/CD pipelines using **GitHub Actions**.

## 🚀 Features
- Automated code testing and validation on every `push` to the `main` branch.
- PHP environment setup via GitHub Actions workflows.

## 📂 Project Structure
- `index.php`: Sample application file.
- `.github/workflows/pipeline.yml`: Automated CI/CD pipeline configuration.
